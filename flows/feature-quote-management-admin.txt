FLUJO: Gestion de cotizaciones (vista admin)
FUENTE: .kiro/specs/feature-quote-management-admin/design.md

QUE RESUELVE
Vista administrativa para gestionar las cotizaciones del Flujo B. Permite
listar, buscar, filtrar, ver detalle con timeline de estados, y postergar
fechas de entrega con notificacion al cliente.

ACTORES INVOLUCRADOS
- Admin (desde admin-dashboard)
- api-core (NestJS, endpoints de lectura y postergacion)
- Mailjet (email de postergacion al cliente)

PASO A PASO
1. Admin accede a la seccion de cotizaciones en el dashboard (/quotes).
2. GET /api/quotes con filtros: status, busqueda (q), paginacion.
3. Frontend renderiza QuotesTable con filtro de status + busqueda debounced + paginacion (20 por pagina).
4. El listado por defecto ("Todas") excluye cotizaciones archivadas y descartadas. Para ver archivadas: /quotes/archived.
5. Admin hace clic en una cotizacion -> vista de detalle con TimelineStatus (componente visual que muestra la secuencia de estados con timestamps calculados: quote_sent_at, accepted_at, rejected_at, etc.).
6. Admin puede cotizar: boton "Cotizar" abre modal con precio, dias de entrega, fecha estimada.
7. Admin puede archivar: cotizaciones rechazadas, expiradas o con pago expirado se archivan para mantener limpia la tabla principal.
8. Cotizaciones archivadas se acceden desde /quotes/archived con su propia busqueda y paginacion.

ESTADOS
No tiene estados propios. Opera sobre los estados del Quote definido en feature-custom-quote.

ENDPOINTS INVOLUCRADOS
GET /api/quotes                          -> listado con filtros (status, q, page). Default excluye archived y discarded.
GET /api/quotes?status=archived          -> solo archivadas (usado por /quotes/archived)
PATCH /api/quotes/:id/present            -> admin presenta cotizacion con precio
PATCH /api/quotes/:id/archive            -> archiva cotizacion (admin, JWT)

RUTAS FRONTEND (Admin Dashboard)
/quotes                                  -> tabla principal (sin archivadas)
/quotes/archived                         -> tabla de cotizaciones archivadas

DEPENDENCIAS CON OTROS FLUJOS
- feature-custom-quote: depende totalmente del dominio Quote (misma entidad, mismos estados).
- feature-i18n-localization: email de postergacion en idioma del registro.
- feature-order-delivery-schedule: reutiliza mecanismo de postergacion.
- feature-realtime-notifications: notificaciones de nuevas cotizaciones.

NOTAS / DECISIONES DE DISENO RELEVANTES
- Este feature NO crea entidad nueva. Opera sobre el Quote ya definido en feature-custom-quote.
- TimelineStatus es un componente visual candidato a reutilizarse en packages/ si se usa en orders tambien.
- Las tareas de este feature solo se ejecutan despues de que feature-custom-quote migre su data model.
- El timeline se calcula a partir de timestamps ya almacenados (quote_sent_at, accepted_at, rejected_at, paid_at, etc.).
